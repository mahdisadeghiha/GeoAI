# GeoAI HTML Documentation Site

چندصفحه‌ای، فارسی، با طراحی هم‌راستا با داشبورد GeoAI.

## باز کردن

فایل [`site/index.html`](site/index.html) را در مرورگر باز کنید، یا از ریشه پروژه:

```bash
# اختیاری: سرو ساده
python -m http.server 5500 --directory docs/site
```

سپس: `http://127.0.0.1:5500`

## صفحات

| فایل | محتوا |
|---|---|
| `site/index.html` | معرفی پروژه و نقشه راه مستندات |
| `site/urbanism.html` | نگاه شهرسازی و محدوده‌های عمان |
| `site/technology.html` | معماری و پشته فناوری |
| `site/pipeline.html` | خط لوله پردازش داده |
| `site/methods.html` | شاخص‌های طیفی و روش‌های تشخیص تغییر |
| `site/guide.html` | نصب، داشبورد و API |
