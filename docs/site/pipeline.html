From GeoTIFF to Intelligence

خط لوله پردازش داده

هر اجرای تحلیل یک مسیر مشخص را طی می‌کند: اعتبارسنجی ورودی، هم‌ترازسازی زمانی-مکانی، محاسبه شاخص‌ها، تشخیص تغییر، و تبدیل به لایه‌های قابل‌نمایش و آمار.

T1/T2 GeoTIFF→ Validate→ CRS / Reproject→ Align / Crop→ NoData→ NDVI + Change→ Polygonize→ Stats + Map PNG

مراحل گام‌به‌گام

۱

Validation

وجود فایل، CRS، transform و حداقل تعداد باند بررسی می‌شود.

۲

CRS Check & Reproject

هر دو تصویر به CRS هدف (مثلاً EPSG:32640 برای مسقط) منتقل می‌شوند.

۳

Alignment

شبکه مشترک با رزولوشن X/Y مناسب ساخته می‌شود تا پیکسل‌ها روی هم بیفتند.

۴

AOI Crop

اگر کاربر AOI بکشد، رستر به همان قاب برش می‌خورد؛ در غیر این صورت کل تصویر پردازش می‌شود.

۵

NoData Mask

پیکسل‌های نامعتبر حذف می‌شوند تا آمار فقط روی داده معتبر محاسبه شود.

۶

Indices & Detection

NDVI/NDBI و ماسک تغییر ساخته می‌شود (baseline یا CVA).

۷

Spatial Analysis

Connected components → polygonize → GeoJSON با مساحت و امتیاز.

۸

Preview Export

PNGهای RGB، NDVI diff و change mask برای Leaflet تولید می‌شوند.

ورودی‌ها و خروجی‌ها

ورودی

  • جفت GeoTIFF چندباندی (T1 و T2)
  • یا نمونه‌های data/samples/
  • سال‌ها، شناسه محدوده، AOI اختیاری
  • روش: baseline یا cva

خروجی در data/processed/<run_id>/

  • change_mask.tif / .png
  • ndvi_*.tif و ndvi_diff.png
  • rgb_t1.png / rgb_t2.png
  • change_regions.geojson
  • آمار و metrics گسترش‌یافته

داده واقعی در برابر نمونه

برای دموی آفلاین از رسترهای مصنوعی منسجم استفاده می‌شود. برای تحلیل واقعی، کامپوزیت Sentinel-2 از Planetary Computer با اسکریپت‌های scripts/download_oman.py یا scripts/download_sentinel2.py قابل دریافت است.
